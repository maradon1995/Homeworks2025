Внутрішні відступи "padding":

Властивість padding — це внутрішній відступ. Використовується для відступів від кордону блоку всередину блоку (елементу), а не між блоками (елементами). Значення можуть бути лише додатними, тобто більше або рівне нулю.
Простими словами `padding` — це Відступи ВСЕРЕДИНІ об'єкту, від кордонів об'єкта ДО ЙОГО КОНТЕНТУ. НЕ успадковується. При вказанні значення у відсотках, відсоток береться від ширини батьківського об'єкта, навіть для вертикальних відступів. НА ЦЕЙ ЕЛЕМЕНТ, ЯКИЙ Є ТИПОМ "inline", внутрішній відступ зверху та знизу веде себе не передбачувано!!!

Зовнішні відступи "margin":

Властивість margin — Зовнішній відступ. Використовується для відступів між блоками (елементами), рекомендується робити відступи зверху вниз (margin-bottom) зліва на право. Значення можуть бути від'ємними! НЕ успадковується.
Властивість "margin" має такі ж самі параметри, що і властивість "padding". Правило: margin-top та margin-bottom на inline елементи не діють, тому можна навіть і не вказувати

Ширина блоку "width":

Властивість width - чітко задає ширину блочного (блочно-рядкового) об'єкту, НЕ працює з рядковими об'єктами

  • auto - (за замовченням) автоматичний розмір.

  • Властивість max-width – встановлює максимальну ширину блочних (блочно-рядкових) тегів, тобто блок не буде більшим за вказану ширину. Не успадковується.

  • Властивість min-width — встановлює мінімальну ширину блочних (блочно-рядкових) тегів, тобто блок не буде меншим за вказану ширину. Не успадковується.

Висота блоку "height":

Властивість height — встановлює чітку висоту блочних (блочно-рядкових) тегів. Не успадковується. НЕ працює з рядковими об'єктами

  • auto - (за замовченням) автоматичний розмір.

  • Властивість max-height — встановлює максимальну висоту блочних (блочно-рядкових) тегів, тобто блок не буде більшим за вказану висоту. Не успадковується.

  • Властивість min-height — встановлює мінімальну висоту блочних (блочно-рядкових) тегів, тобто блок не буде меншим за вказану висоту. Не успадковується.

Властивість "box-sizing":

Властивість `box-sizing` Застосовується для зміни алгоритму обчислення величин. Значення властивості:

  • content-box - (за замовченням) додає відступи до розміру об'єкта;
  • border-box - значення розмірів враховують відступи.

ВАЖЛИВО! Видалення фантомних відступів між елементами.

Для батьківського елементу вказуємо font-size: 0; це прибере фантомний відступ між елементами яким вказано display: inline-block; а для дочірніх елементів потрібно вказати відповідний розмір шрифту, приклад font-size: 16px;

Властивість "vertical-align":

Властивість vertical-align — керує вирівнюванням блочно-рядкових та рядкових елементів по вертикалі (осі - Y) Не успадковується.

top — вирівнює по верхньому краю

middle — вирівнює по центру.

bottom — вирівнює по нижньому краю

Властивість "display":

Властивість display — багатоцільова властивість яка задає глобальні параметри тегу, не успадковується. block — елемент відображається як блочний (встановлено за замовченням для блочних об'єктів); inline — елемент відображається як рядковий (встановлено за замовченням для рядкових об'єктів);
inline-block — елемент відображається як рядковий, але з можливістю використання усіх CSS-властивостей (блочно-рядковий); Щоб тут не було написано, всеодно з display: none; ти мене не будеш бачити, до поки я того не схочу.
