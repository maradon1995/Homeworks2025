Властивість "border:"

Унаверсальна властивість встановлює товщину, стиль та колір границі навколо елемента. "Не успадковується". Синтаксис - border: 5px solid black, де 5px - ширина border, solid - стиль, black - колір.

  • solid - звичайна пряма лінія без крапок чи штрихів
  • dotted - точкова (крапкова) лінія.
  • dashed - пунктирна лінія
  • double - подвійна суцільна лінія (майже ніколи не використовується)

На inline типи властивість діє непередбачувано.

Одностороннє використання "border:"

  • border-left - border зліва
  • border-right - border справа
  • border-top - border зверху
  • border-bottom - border внизу

Властивість "outline:"

Унаверсальна властивість встановлює товщину, стиль та колір обводки навколо елемента. "Не успадковується". Відмінність від "border" в тому, що він обводить елемент ззовні, а не працює, як бордер і не стискає елемент в середині батьківського. Значення ідентичні властивості "border". Також "outline" не може використовуватись на якусь окрему сторону елемента. Синтаксис - outline: 1px solid black, де 5px - ширина border, solid - стиль, black - колір.

  • solid
  • dotted
  • dashed
  • double

outline-offset: 10px; - збільшує зовнішню відстань самої лінії від елемента на вказану кількість пікселів.

Властивість "box-shadow:"

Властивість box-shadow — додає тінь до елементу. "Не успадковується". Вона може бути як і зовні об’єкту, так і всередині. Синтаксис - box-shadow: 1px 1px 5px black, де 1px - ширина по горизонталі, 1px - ширина по вертикалі, 5px - ширина розсіювання тіні, black - колір.

приклад:

box-shadow : 1px 1px 5px black;

Властивість "opacity:" та "visability:"

Властивість opacity — встановлює рівень прозорості елемента. "Не успадковується".

  • 0 — повна прозорість; мене не видно
  • 1 — повна непрозорість (за замовченням);
  • 0.5 — прозорість 50%.

Властивість visibility — управляє відображенням елемента.

  • visible — відображає об'єкт (за замовченням);
  • hidden — ховає об'єкт (з об'єктом не можна взаємодіяти).

  • Властивість background-image встановлює фонове зображення елемента або задати градієнтну заливку:

Властивість background-repeat визначає як повторюватиметься фонове зображення

  • background-repeat: repeat; — за замовченням (зображення повторюється для заповнення блоку);
  • background-repeat: no-repeat; — не повторювати (зображення не повторюється для заповнення блоку);
  • background-repeat: repeat-x; — повторювати по горизонталі (зображення повторюється лише по горизонталі для заповнення блоку);
  • background-repeat: repeat-y; — повторювати по вертикалі (зображення повторюється лише по вертикалі для заповнення блоку).

Властивість background-position задає початкове положення фонового зображення

background-position: 0 0; перше значення — розташування по горизонталі (значення може бути у відсотках, px, словом), друге значення — по вертикалі.

  • 0 0 (або left top) — за замовченням (зображення буде починатись з верхнього лівого кута блоку);
  • center (або 50%) — центрує зображення посередині блоку; Так само із іншими позиціями, такими як: top, left, bottom, right

Властивість background-attachment встановлює чи прокручуватиметься фонове зображення разом із вмістом елемента background-attachment: scroll;

  • scroll — скролиться разом з блоком (за замовченням);

Властивість background-size масштабує фонове зображення згідно з заданими розмірами у цифрах

  • background-size: auto auto; — за замовчуванням. Зображення збільшиться відповідно наповненості блоку.
  • background-size: auto 100px;
  • background-size: contain;
  • Можемо написати тільки ширину, і висота підтягнеться автоматично та пропорційно: background-size: 300px;

ВАЖЛИВО! Спеціальні значення contain та cover:

  • contain — масштабує зображення таким чином, щоб картинка повністю помістилася всередину блоку. Тобто по найменшій частині картинки (висота, якщо зображення горизонтальне, або ширина). Підходить для фотографій та карток товарів.
  • cover — масштабує зображення так, щоб воно зайняло увесь блок (тому частину ми не будемо бачити). Тобто по найбільшої частини картинки. Підходить для фонових зображень які не несуть в собі конкретної інформації, а використовуються для декору та підкреслення основної інформації (контенту).

Властивість background-clip Налаштовує поведінку фонового зображення разом з межею border та текстом

background-clip: text; - властивість CSS використовується для застосування фону (кольору, градієнта або зображення) до текстового вмісту елемента, а не до всього елемента. Це створює візуально привабливі ефекти, такі як текст із градієнтним заповненням.
