Позиціонування в CSS

Позиціонування в CSS — це механізм, який визначає, як та де елементи розташовуються на веб-сторінці відносно їхнього звичайного потоку, батьківських елементів та інших сусідніх об’єктів, також як вони реагують на зміни розміру вікна чи контейнера. CSS надає кілька основних типів позиціонування:

Статичне (static)

position: static — це значення властивості position у CSS, яке є значенням за замовчуванням. Елементи зі static позиціонуванням розташовуються у звичайному потоці документа, тобто в тому порядку, в якому вони йдуть в HTML-коді. Вони не підлягають зміщенню за допомогою властивостей top, right, bottom або left.

Відносне (relative)

position: relative; — об'єкт позиціонується відносно свого поточного місця положення в коді. З position:relative; працюють властивості top, left, right, bottom та z-index

Абсолютне (absolute)

position: absolute; — абсолютне (безумовне) позиціонування. Об'єкт позиціонується відносно першого батьківського елементу, position якого відмінний від static. Об'єкт втрачає свою блочну сутність та простір який він займав.

Фіксоване (fixed)

position: fixed; — фіксоване позиціонування відносно вікна браузера (вюпорта). Об'єкт втрачає блочну сутність, положення в коді, простір. Не бере участі у скролі (не скролиться з контентом).

Липке (sticky)

position: sticky; — гібридне поєднання значень static та fixed. Спочатку елемент поводитися як static, але після того, як скрол доходить до нього, стає fixed. Залишається блочним.

ВАЖЛИВО! Не працює, якщо у батьківських об'єктах присутній overflow: hidden; Працює з новим значенням overflow: clip для батьківських блоків.
