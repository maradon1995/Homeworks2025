Lesson 11: Transform

Трансформація, властивість transform

За допомогою 2D та 3D трансформації можна зміщувати, повертати, масштабувати елементи та інше. Задається трансформація властивістю transform та її значеннями. При вказанні відсоткових значень відсотки беруться від розміру об’єкта x - від ширини y - від висоти

2D Трансформації

  • transform: translate;

    Зміщує елемент на нове місце відносно початкового положення вправо та вниз через координати X та Y.

  • transform: scale (x, y);

    задає масштабування для елементу по окремої осі x та y

  • transform: rotate (deg);

    Повертає елементи, додатні значення (10deg) повертають елемент по годинниковій стрілці, від’ємні проти годинникової стрілки.

  • transform: skew (xdeg, ydeg);

    Нахиляє елементи.

  • transform: matrix (a, c, b, d, x, y);

    Дозволяє об'єднати кілька функцій 2D-трансформацій в одній, рідко використовується.

translate: 20px -10px
transform: translateY(30px)
scale: 1.2
scale: 1.1 1.4
rotate: 45deg
rotate: -240deg
transform: skew(-30deg, 0deg)
transform: translate(20%, 20%) scale(0.5) rotate(30deg) skew(20deg, 20deg)
